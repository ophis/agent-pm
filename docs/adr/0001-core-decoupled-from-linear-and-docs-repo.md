# Core skill pack decoupled from Linear and the docs repo

Roles and tasks become a core pack that takes free text and returns Markdown, knowing nothing of Linear, and no role or task text names where documents are stored. A task's `[output]` config names its destination (e.g. GitHub `ophis/private_docs`, or local); the composer compiles the matching delivery steps into the prompt and the run delivers the document itself. An orchestration layer turns an issue into free text, calls the core, and writes back to Linear. Git and GitHub as tools stay available to the core: an engineering run still commits and pushes to its target repo, and research still cites GitHub permalinks. The pack targets Claude Code only for now; its Claude-only dependencies (`/deep-research`, ultracode Workflow rounds, `autopilot:build`) stay until a later extraction.

The core pack holds only roles, tasks, principles, templates and the delegate. Ticketing (issues, statuses, comments, hand-offs, questions to the user) and orchestration (scheduling, claiming, resuming) live outside it; a run reports its outcome to its caller, and each ticketing integration maps that outcome to its own actions.
